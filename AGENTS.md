# AGENTS.md

This repository is a collection of custom [pi](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent) extensions.

## Repo conventions

- One directory per extension: `<name>/<name>.ts` + `<name>/README.md`
- The root `README.md` holds the extension index — update it when adding or removing an extension
- Extensions are symlinked into `~/.pi/agent/extensions/` (see root README)
- No issue tracker: work happens on a branch and ships as a GitHub PR
